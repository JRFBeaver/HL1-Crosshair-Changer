[РУССКИЙ / RUSSIAN]

ОПИСАНИЕ:
Утилита для быстрой и удобной замены стандартного прицела в игре Half-Life 1
(включая актуальную версию Steam 25th Anniversary Update). Программа
автоматически генерирует спрайты на лету с поддержкой любого цвета из
палитры RGB и корректно настраивает отображение на всех разрешениях экрана.

ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ИСПОЛЬЗОВАНИЮ:
1. Распакуйте все файлы из архива в корневую папку с игрой Half-Life
   (например: C:\Program Files (x86)\Steam\steamapps\common\Half-Life)
   или в любую удобную папку на вашем компьютере.
2. Запустите файл "Run_HL1_Crosshair_Changer.bat".
   При первом запуске скрипт автоматически соберет исполняемый файл
   "HL1_Crosshair_Changer.exe" с фирменным значком (буква C и монтировка).
   В дальнейшем вы можете запускать напрямую "HL1_Crosshair_Changer.exe".
3. В открывшемся окне программы:
   - Убедитесь, что путь к папке Half-Life определился верно (либо укажите
     его вручную через кнопку "Обзор...").
   - Выберите понравившуюся форму прицела (круги, точки или V-образные
     прицелы разных размеров).
   - Выберите цвет из списка пресетов или нажмите кнопку "Палитра RGB...",
     чтобы задать абсолютно любой собственный оттенок.
   - Нажмите кнопку "УСТАНОВИТЬ ПРИЦЕЛ".
4. Запустите (или перезапустите) Half-Life и наслаждайтесь игрой!

ВОЗВРАТ СТАНДАРТНОГО ПРИЦЕЛА:
Перед первой установкой программа автоматически сохраняет резервные копии
оригинальных файлов игры (.bak). Чтобы вернуть стандартные прицелы Valve в
один клик, просто нажмите кнопку "ВЕРНУТЬ СТАНДАРТНЫЙ".

[АНГЛИЙСКИЙ / ENGLISH]

DESCRIPTION:
A lightweight utility designed to easily customize and replace the default
crosshair in Half-Life 1 (fully compatible with the Steam 25th Anniversary
Update). The program procedurally compiles GoldSrc sprites (.spr) on the fly,
supporting custom RGB colors and all screen resolutions.

INSTALLATION & USAGE GUIDE:
1. Extract all files from the ZIP archive into your Half-Life root directory
   (e.g., C:\Program Files (x86)\Steam\steamapps\common\Half-Life)
   or into any folder on your PC.
2. Run "Run_HL1_Crosshair_Changer.bat".
   On first launch, it will automatically compile the standalone application
   "HL1_Crosshair_Changer.exe" with its custom Crowbar-C icon. Afterwards,
   you can launch "HL1_Crosshair_Changer.exe" directly.
3. Inside the application window:
   - Verify that your Half-Life folder path is detected properly (or click
     "Обзор..." / Browse to select it manually).
   - Select your preferred crosshair shape (Circles, Dots, or V-Chevrons).
   - Choose a color preset or click "Палитра RGB..." to pick any custom RGB
     color via the color wheel.
   - Click "УСТАНОВИТЬ ПРИЦЕЛ" (Install Crosshair).
4. Launch (or restart) Half-Life and enjoy!

RESTORING DEFAULT CROSSHAIRS:
The utility automatically backs up original game files (.bak) before making
changes. To revert to the original Valve crosshairs at any time, simply click
"ВЕРНУТЬ СТАНДАРТНЫЙ" (Restore Default).
