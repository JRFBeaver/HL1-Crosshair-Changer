[ENGLISH]

DESCRIPTION:
A lightweight utility designed to easily customize and replace the default
crosshair in Half-Life 1 (fully compatible with the Steam 25th Anniversary
Update on both Windows and Linux). The program procedurally compiles GoldSrc
sprites (.spr) on the fly, supporting Circles, Brackets (.), V-Chevrons, Dots,
custom RGB colors, and all screen resolutions.
Interface language defaults to English and can be switched to Russian anytime
via the top-right "Lang: EN / RU" button.

INSTALLATION & USAGE (WINDOWS):
1. Extract all files from the ZIP archive into your Half-Life root directory
   (e.g., C:\Program Files (x86)\Steam\steamapps\common\Half-Life)
   or into any folder on your PC.
2. Run "Run_HL1_Crosshair_Changer.bat".
   On first launch, it will automatically compile the standalone application
   "HL1_Crosshair_Changer.exe" with its custom Crowbar-C icon. Afterwards,
   you can launch "HL1_Crosshair_Changer.exe" directly.
3. Choose your preferred crosshair shape, color (or custom RGB palette), and
   click "INSTALL CROSSHAIR".

INSTALLATION & USAGE (LINUX / STEAM DECK):
1. Extract the archive into your Half-Life folder (or any directory).
2. Run "./Run_HL1_Crosshair_Changer_Linux.sh" (or launch
   "python3 HL1_Crosshair_Changer_Linux.py" directly).
3. The Linux version automatically detects standard Steam paths
   (~/.steam/steam/steamapps/common/Half-Life). Select your shape and color,
   then click "INSTALL CROSSHAIR".

RESTORING DEFAULT CROSSHAIRS:
The utility automatically backs up original game files (.bak) before making
changes. To revert to the original Valve crosshairs at any time, simply click
"RESTORE DEFAULT".

[РУССКИЙ / RUSSIAN]

ОПИСАНИЕ:
Утилита для быстрой и удобной замены стандартного прицела в игре Half-Life 1
(включая актуальную версию Steam 25th Anniversary Update для Windows и Linux).
Программа автоматически генерирует спрайты (.spr) на лету с поддержкой кругов,
скобок (.) с точкой, V-образных прицелов, точек, любого цвета из палитры RGB
и корректно настраивает отображение на всех разрешениях экрана.
По умолчанию в программе включен английский язык — переключиться на русский
можно в один клик кнопкой "Lang: EN / Язык: RU" в правом верхнем углу окна.

ИНСТРУКЦИЯ ПО УСТАНОВКЕ (WINDOWS):
1. Распакуйте все файлы из архива в корневую папку с игрой Half-Life
   или в любую удобную папку на вашем компьютере.
2. Запустите файл "Run_HL1_Crosshair_Changer.bat".
   При первом запуске скрипт автоматически соберет исполняемый файл
   "HL1_Crosshair_Changer.exe" с фирменным значком (буква C и монтировка).
3. Выберите форму прицела, цвет (или "Палитра RGB...") и нажмите
   "УСТАНОВИТЬ ПРИЦЕЛ".

ИНСТРУКЦИЯ ПО УСТАНОВКЕ (LINUX / STEAM DECK):
1. Распакуйте архив в папку с игрой или в любую удобную директорию.
2. Запустите скрипт "./Run_HL1_Crosshair_Changer_Linux.sh" (либо запустите
   "python3 HL1_Crosshair_Changer_Linux.py").
3. Выберите нужный прицел и нажмите "УСТАНОВИТЬ ПРИЦЕЛ".

ВОЗВРАТ СТАНДАРТНОГО ПРИЦЕЛА:
Чтобы вернуть стандартные прицелы Valve в один клик, просто нажмите кнопку
"ВЕРНУТЬ СТАНДАРТНЫЙ" (Restore Default).
