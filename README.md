# HL1-Crosshair-Changer
This is a simple piece of software for changing the crosshair in the game Half-Life; it replaces the default in-game crosshair sprites with ones that are more convenient to use.

"The program is automatically compiled from the source code the first time the .bat file is run. You can personally inspect the .cs file using Notepad to verify the software's safety."

Check File README_RU_EN.txt for more INFO.
